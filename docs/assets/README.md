# Presentation Assets

This directory contains captured repository-local screenshots and is reserved for short demo media.

Available assets:

| Asset | Purpose | Capture notes |
| --- | --- | --- |
| `auction-live.png` | Single auction detail screen showing an open auction, current bid, bid history, and live connection. | Captured from the MacBook Pro auction after `scripts\reset-demo.ps1`. |
| `auction-two-clients.png` | Two browser clients viewing the same auction with synchronized state. | Captured side by side, one acting as Alice and one as Bob. |
| `auction-closed.png` | Closed auction state with final price, winner, and disabled bid controls. | Captured from the real closed UI state. |
| `auction-demo.gif` | Optional future short animated demo of bidding, live propagation, automatic close, and winner selection. | Not created yet; keep around 10-20 seconds when added. |

Do not commit placeholder binary files. Add `auction-demo.gif` only after a real capture is created from the running demo.
